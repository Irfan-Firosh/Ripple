# Landing walkthrough

The landing page uses recorded current product components, real audience profiles and saved campaign/Lab results. Dark and light assets are generated separately. The October 4 recording uses TryCua's generated campaign `26654684-3c5e-4a79-b751-f2a4258c91ff` and completed experiment `22`.

The five chapters show the audience map, generated campaign image/video, Lab tweet cards and reaction browsing, the illustrative A/B spread, and the recorded engagement charts. Chapters crossfade over 650ms rather than cutting abruptly. The resulting video is about 39.4 seconds long. The landing player loops silently, pauses offscreen or in a hidden tab, respects reduced motion and has a single pause/play button. It has no timeline, elapsed-time display or playback bar. Native controls on inner campaign videos are hidden only in the recording.

`npm run render:demo` requires the local Vite server and FFmpeg. `DEMO_BRAND`, `DEMO_THEME` and `DEMO_URL` are optional. The script selects a real completed generated campaign; missing data fails the recording rather than substituting placeholder material. The campaign film mode reviews saved image/video drafts and disables automatic generation, copy, video and media-attachment effects. Reducer HTTP requests are blocked and fail the capture. The recording does not start paid inference or modify backend data.

The feature section uses original animated SVG concepts, following the supplied reference's thin luminous lines and spatial geometry: connected audience orbits, an idea becoming an image/video pair, and A/B signal curves. They adapt to both themes and become still under reduced motion. They are decorative concepts, not screenshots or claimed measured results. Four native expandable FAQ rows cover starting with an X handle, generated media, simulation estimates and publishing. The footer credits **Made with ♥ by Irfan & Ansh**. Landing research/design links have been removed; the documents remain available in the repo.

`npm run build` verifies TypeScript and the production bundle. `tests/landing.spec.ts` checks video playback without controls or timeline, feature illustrations in both themes, FAQ expansion, creator credit, reduced motion, retry, auth navigation, phone overflow and the live current audience/Lab film.
