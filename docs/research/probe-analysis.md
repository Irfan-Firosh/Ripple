# Probe (tryprobe.io): reference analysis for Ripple

Researched 2026-10-01. Probe is the reference for a feature to add to Ripple.

## What Probe is

[Probe AI](https://tryprobe.io/) is a pay-per-query deep-research product (support contact: support@ashlr.ai). Its pitch is: "16 AI agents search the web and X/Twitter in parallel, synthesizing everything into structured intelligence reports."

| Aspect             | Details (from tryprobe.io, /how-it-works, /pricing, /about)                                                                                                                        |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Flow               | 1. **Clarifying questions** to set the scope. 2. **Agents fan out** in parallel across the web, X, news and data. 3. A **structured report** comes back.                           |
| Fan-out            | Up to 16 parallel agents per query, and "80+ agent Swarm mode" on the top tier. Each agent "pursues a different line of inquiry", and their findings are merged into one report.   |
| Live X data        | It says its X access is "Powered by xAI Grok": live, not cached. This is its main claimed difference from ChatGPT and Perplexity.                                                  |
| Report format      | Executive Summary, Key Findings, Market & Social Sentiment, Sources & Evidence, Key Takeaways. Every claim has a numbered citation.                                                |
| Live visualization | A "real-time agent progress grid" (AgentGrid) shows each agent's progress while it runs.                                                                                           |
| Pricing tiers      | Flash $0.15 (1 agent, ~15s); Quick $0.50 (1 agent, ~30s); Deep $2 (4 agents); Deep+ $5 (16 agents, ~1 min). Credit packs; follow-up questions are free; $5 free credits on signup. |
| Extras             | Export to PDF/Word/Excel/HTML, voice and file input, follow-up questions on finished reports.                                                                                      |
| Users              | Crypto traders, VC due-diligence analysts, market analysts, brand/PR teams, journalists, consultants.                                                                              |

**Traction is tiny.** The LinkedIn company page shows 2 followers. A third-party estimate puts the site at about 1.8k visits a month ([LinkedIn listing](https://linkedin.com/company/probe-deep-research)). The "100+ researchers" and testimonial claims come from Probe itself and are unverified.

## How Probe gets live X data (verified)

- The xAI API has a server-side **`x_search`** tool. It does keyword search, semantic search, user search and thread fetching on X ([docs](https://docs.x.ai/developers/tools/x-search)).
- Search filters: `allowed_x_handles` / `excluded_x_handles` (up to 20 handles each), `from_date` / `to_date`, plus image and video understanding.
- Results come back with source citations.
- Price: **$5 per 1,000 `x_search` calls**, plus model tokens. `web_search` costs the same ([pricing](https://docs.x.ai/developers/pricing)).
- Model price example: grok-4.3 is $1.25 per million input tokens and $2.50 per million output ([x.ai/api](https://x.ai/api)).
- **Why this matters for Ripple:** this is a cheap, legitimate way to get _aggregate_ live signal from X ("what are people in AI-founder circles talking about this week?"). It avoids the pay-per-record X API that [ripple-fact-check.md](ripple-fact-check.md) ruled out.
- **Caveat:** it returns Grok-synthesized search results, not a follower graph or "who reposted" data. It cannot replace Bluesky as the source of the graph.
- **Terms (not verified):** whether xAI's API terms restrict _per-person_ behavioral profiling from `x_search` results. The safe position is to use it only for topic and narrative signal, never to build per-account twins.

## What Ripple can borrow from Probe

| Probe pattern                                | Ripple counterpart                                                                                                                                                                                                     | Fit                                                                      |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Parallel research agents with a cited report | A **scout swarm** that maps what each audience community is talking about _right now_ (web + X via Grok + Bluesky), before drafts are written or simulated. This fills the "discover narrative" step of Ripple's loop. | Strong. More Fetch.ai multi-agent work; the xAI sponsor gets a real job. |
| Clarifying questions before running          | Ripple's form card already asks for the audience and run count. Extend it to the target community and goal.                                                                                                            | Strong and cheap. Maps directly to ASI:One form cards.                   |
| Depth tiers sold per query                   | Simulation depth tiers (runs × graph hops × scout count), charged through the Fetch.ai Payment Protocol.                                                                                                               | Strong. Gives the "credible monetization model" Fetch.ai rewards.        |
| Live agent grid                              | Ripple already plans a live network view. A scout grid is a second live panel.                                                                                                                                         | Medium. Visual, but competes with the network view for attention.        |
| Structured, cited report + export            | A "Ripple brief": winner, why, which communities it enters, the narrative evidence behind it, with citations.                                                                                                          | Medium. Good for the demo and the Devpost description.                   |
| Free follow-ups                              | Counterfactual re-runs ("change the hook") as chat follow-ups.                                                                                                                                                         | Already in the spec.                                                     |

## Positioning

- **Probe answers "what is being said?"** **Ripple answers "what will happen if _I_ say this?"**
- Adding a Probe-style scout layer turns Ripple into the full loop: **discover the narrative, draft, simulate the spread, pick the winner, post, recalibrate.**
- Don't pitch Ripple as "Probe plus a simulator". Probe is a small product and judges won't know it. Pitch the scout swarm as part of Ripple itself.

## Source access for Ripple Discover (verified 2026-10-01)

Discover covers "the major public social web", not every platform.

| Source             | Access                                                                                                                                                                                                                                                                                                                                                                  | Limits that shape the design                                                                                                                                                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bluesky**        | Free public AppView API plus the Jetstream firehose (see [ripple-fact-check.md](ripple-fact-check.md))                                                                                                                                                                                                                                                                  | Rate limits are "generous" but no numbers are published.                                                                                                                                                                                                      |
| **X**              | Grok `x_search`, $5 per 1,000 calls plus tokens, with citations                                                                                                                                                                                                                                                                                                         | Aggregate signal only; no follower graph. Never use it for per-person profiles.                                                                                                                                                                               |
| **Web / news**     | Grok `web_search` ($5 per 1,000 calls) or Exa                                                                                                                                                                                                                                                                                                                           | Paid per call.                                                                                                                                                                                                                                                |
| **Reddit**         | Free OAuth, 100 queries per minute ([wiki](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki))                                                                                                                                                                                                                                       | Commercial use needs a paid agreement.                                                                                                                                                                                                                        |
| **YouTube**        | Data API v3 with a free API key. The default quota is **10,000 units a day** for read endpoints. `videos.list`, `commentThreads.list` and `channels.list` cost 1 unit each. **`search.list` has its own bucket of 100 calls a day** (it moved to a granular quota on June 1, 2026) ([quota calculator](https://developers.google.com/youtube/v3/determine_quota_cost)). | **Only 100 searches a day.** Run a few searches, cache them, then spend the 10k pool on `videos.list` stats and `commentThreads.list`. Raising the quota requires Google's audit form.                                                                        |
| **Hacker News**    | Algolia HN Search API, free, no API key: `/api/v1/search` (by relevance) and `/api/v1/search_by_date`, with tags (`story`, `comment`, `ask_hn`, `show_hn`) and numeric filters (`points`, `num_comments`, `created_at_i`) ([docs](https://hn.algolia.com/api))                                                                                                          | **Each query returns at most 1,000 hits.** Split long time ranges into windows ([issue #230](https://github.com/algolia/hn-search/issues/230)). The rate limit isn't documented on the API page, so the commonly cited 10,000 requests an hour is unverified. |
| TikTok / Instagram | No practical public API for this use                                                                                                                                                                                                                                                                                                                                    | Covered only indirectly, through web search.                                                                                                                                                                                                                  |
